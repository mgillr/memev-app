# macOS toolkit

Not built on this runner.

The chosen toolkit is AppKit in Swift. The floor is macOS 12. The build uses the Command Line Tools and does not require `xcodebuild`. A disk image and ad hoc signing are later work, and they need a Mac.

This directory is a marker so the Linux slice is not mistaken for a Mac build. There is no Swift source here yet, because it cannot be compiled or run in this environment and an unbuilt file would not be evidence.
