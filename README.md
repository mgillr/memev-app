# Memev desktop app

Native programs for macOS, Windows and Linux. Each reads a Memev core on the same computer. The core stays in the memev repository.

The first slice is a Linux window in `native/linux`. On a first launch it asks which computer this is, where the notes go, which apps are listed by the core, and whether to record your own git remote, then checks a saved note with that core. See `native/SLICE.md` and `native/CLI-CONTRACT.md`. macOS and Windows are not built here.

Nothing is released from this repository.
